# projAIBEN_vehicle_detection

Vehicle detection project using nuScenes and EfficientDet.

## Structure
- `data/`: Raw, processed, and split data
- `models/`: Model checkpoints and ONNX exports
- `src/`: Source code for conversion, training, inference, and utilities
- `notebooks/`: Data exploration and sanity checks
- `config.yaml`: Configuration file
- `requirements.txt`: Python dependencies
